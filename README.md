# normalize-data-web-ui

Vite + React + TypeScript + Tailwind CSS v4 + Zustand + TanStack Virtual + PapaParse.

```sh
npm install
npm run dev
```

## Structure

- `src/store/` — Zustand stores
- `src/lib/` — helpers (CSV parsing via PapaParse)
- `src/components/` — UI (virtualized table via `@tanstack/react-virtual`)
